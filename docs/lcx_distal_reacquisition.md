# LCX distal source-CCTA reacquisition

This experiment extends the established C6 parent-continuation and C7 daughter paths beyond their current endpoints using source-CCTA information only. Chamber anatomy is deliberately excluded from path generation.

Each vessel must first rediscover its own terminal ~3 mm using the same multiscale 3-D vesselness, HU, and current/legacy coronary-mask field used for distal search. If either positive control fails, distal interpretation is invalid.

Accepted distal candidates must add >=3 mm, project forward >=2 mm, have tortuosity <=1.9, maximum turn <=65 degrees, p10 vesselness >=60% of the adaptive terminal threshold, robust-HU fraction >=0.90, and union coronary-mask support >=0.90. Selection among passing paths prioritizes forward continuation, then dual-mask support and vesselness.

Only after both source-space extensions are frozen is the previously validated direct chamber-interface midpoint construction applied. The RCA/RA-RV positive and LAD/LA-LV negative controls must again pass. The LCX-vs-OM longitudinal identity gate retains the predeclared >=0.08 score margin and requires sufficiently long post-split trajectories; no prior curved-template or AV-groove score is used.

A positive status nominates an LCX-like continuation and an OM-like daughter for visual QC. It does not establish clinical vessel identity, does not resolve LM, and does not modify Master Coronary Anatomy Baseline v2.1.
