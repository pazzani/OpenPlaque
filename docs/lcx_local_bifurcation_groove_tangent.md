# LCX local bifurcation / AV-groove tangent adjudication

Algorithm: `lcx-local-bifurcation-groove-tangent-v1.0`

This experiment is a fresh-baseline source-space anatomy experiment. It begins from the five source paths previously generated by the joint three-vessel search, recomputes their consensus post-LAD trunk, and examines only the **local distal bifurcation geometry**.

## Primary anatomical idea

At a true atrioventricular groove, the local vessel direction should be approximately tangent to both adjacent chamber surfaces. The local chamber-surface normals therefore define an instantaneous groove direction via:

`groove tangent = left-atrium surface normal × left-ventricle surface normal`

Each distal continuation is tested over its first ~4 mm after the shared trunk ends. The primary evidence is:

- alignment with the local LA-LV groove tangent;
- tangency to the left atrial surface;
- tangency to the left ventricular surface;
- continuity with the incoming consensus trunk;
- local left-atrial distance retention;
- current/legacy TotalSegmentator support and source-CCTA contrast.

The accepted RCA is a positive control using the analogous RA-RV groove geometry. The accepted LAD is a negative control for LA-LV groove alignment.

## Scientific boundary

Curved-template similarity is carried only as metadata and contributes zero to the local geometry decision.

A positive result nominates an **LCX-like distal continuation requiring visual/anatomical QC**. It does not establish left-main identity, clinical vessel labeling, circumferential plaque registration, or plaque volume.
